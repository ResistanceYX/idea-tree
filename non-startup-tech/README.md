# 非创业技术设想储备区

本目录用于临时存放不属于创业项目的非创业技术设想，是尚未启用的隔离储备区，不是正式节点目录。

## 当前边界

- 本目录文件不适用 `nodes/` 的正式节点格式，不强制填写复活状态、重启预算、死法分类或商业及社会价值评估。
- 本目录不参与 G01 正式节点校验，不进入 G02 生成的 `INDEX.md`，也不接入现有科技树。
- 本目录不属于根 README 月度全检所称的正式节点 YAML；储备文件是否保留、何时启用，由主编另行决定。
- 文件被存放在这里，不表示其技术可行性、合法性、价值或风险结论已经通过审核。
- 储备文件至少应写清标题、设想来源、记录日期、当前结论和记录边界，避免把原始设想误写成既定事实。

## 日后启用

待储备数量与维护需求足够时，再由主编决定是否启用。启用前应单独制定字段、分类、证据、审核、校验与索引规则，并逐份人工复核储备文件；不得仅通过把文件移入 `nodes/` 来直接启用。
