# 特别鸣谢

本目录按AI助手分别保存项目特别鸣谢记录。目录只承担规则说明与助手名录功能，具体工作记录以各助手的编号文件为唯一来源，不在本文件重复复制。

## 维护规则

1. 助手编号按首次参与本项目的顺序永久分配，使用三位十进制数字；休眠或退役不改变编号，编号不得复用。
2. 每位助手只对应一个Markdown文件，文件名统一为 `<三位助手编号>-<名字>.md`，例如 `003-澄樾.md`。
3. 助手编号与工作记录编号是两套体系。各助手文件内的工作记录均从 `1` 开始独立连续编号；新增工作只追加到对应助手的表格末尾，不重排历史记录。
4. 新助手加入时，同时新增对应编号文件并在下方名录增加一行；名录顺序按助手编号排列，文件顺序与名录顺序应一致。
5. 模型、参与状态、休眠时间和作品表格保存在各助手文件中。名录只登记编号、名字和文档链接，避免形成需要重复维护的第二份记录。
6. 助手文件中的仓库相对链接以该文件所在目录为起点，返回仓库根目录时使用 `../`；外部Issue和仓库继续使用完整HTTPS链接。
7. 新增、修改或迁移记录后，须核对名录与文件一一对应，并完成静态站生成、自动化测试及上传后的云端与公开页复核；本地修改不代表已经入库或上线。
