## 1. 背景与目标

本轮按主编提供的《第六轮修改执行清单》处理七项静态站改进：窄屏两行顶栏及当前页状态、SVG 重绘后的键盘焦点、手机详情与返回闭环、图形和完整列表共享搜索、紧凑加载态及失败回退、默认显示当前视图无连接节点，以及首页四种稳定排序。

本轮只调整展示、交互和渐进增强，不修改节点事实、编号、id、双向关系、复核履历或证据，不增加前端框架、路由库、本地存储和 URL 排序参数，也不改变公开 JSON 字段结构。

云端起稿基线为 [6ad371386cf39afc92d3749eb371eec737c7ab40](https://github.com/ResistanceYX/idea-tree/commit/6ad371386cf39afc92d3749eb371eec737c7ab40)。当时仓库有51个正式节点、277条死法；公开图数据为41对去重关系、34个接入节点和17个孤立节点。清单中的50节点、38对关系等旧数字没有用于新断言。

## 3. 实施与验证流程

1. 合并科技树公共 HTML 骨架，页面只保留一个共享搜索框和一组列表节点；静态 HTML 默认保留完整列表，加载区及增强控件不预先开放，避免无脚本或脚本下载失败时出现永久加载态和死控件。
2. 图形重绘后按 `data-node-id` 重新查询新 SVG 元素再聚焦。桌面键盘选择后焦点留在同一节点；手机点选或键盘选择后聚焦详情标题，返回时优先恢复原节点，不可见时退到关系图标题。
3. 标题、编号和 id 查询同时驱动图形及完整列表。图形继续保留匹配节点和相邻节点；列表只隐藏不匹配条目，不重建或改写关系原文。关系类型及无连接开关只影响图形，定位动作可揭示被搜索或开关暂时隐藏的目标。
4. 数据请求期间，桌面收起长列表并显示紧凑提示；手机无 hash 时保留完整列表。503、非法 JSON 或初始化异常时恢复全部条目、分组、静态计数和档案链接，隐藏增强控件；`ready` 防线避免失败后的 hash 事件重新打开失效图形。`graph.js` 本身被阻断或禁用 JavaScript 时，静态列表从始至终可用。
5. 首页排序只移动既有卡片 DOM。保质期倒序只反转主键，同日期仍按编号正序；搜索、组合筛选和异步全文索引只改变匹配与摘录，不改变当前排序；清除筛选不重置排序，刷新恢复 Python 默认顺序。
6. 最终标准校验得到51个节点、277条死法、390个不同原始链接、876次链接出现、0个错误和22个既有警告。75项单元测试全部通过，INDEX／REVIEW 生成及 `--check` 通过，静态站成功生成51个节点，两份 JavaScript 均通过语法检查。
7. 使用真实 Chromium 完成395项行为断言，动态读取当次 `graph.json` 的51个节点、41条边、34个接入节点和17个孤立节点，没有把当前数量写死为测试预期。
8. 响应式检查覆盖320、390、620、621、768、900、1440px，并单独检查899／900px交互分界。另覆盖桌面及手机延迟请求、合法及非法 hash、503、非法 JSON、阻断 `graph.js`、禁用 JavaScript、减少动态效果和纯键盘闭环。
9. 排序专项覆盖四种顺序、同日期兜底、组合筛选、快速查看展开状态、DOM 身份保留、异步全文索引返回、清除筛选及刷新默认行为。首页统计双向锚点、详情死法展开／收起和死法深链接均回归通过。
10. 已实际查看首页、科技树、加载态、桌面选中、手机详情、返回位置及详情展开截图；未见页面横向溢出、顶栏挤压、当前页状态缺失或详情标题跳出视口。

## 4. 问题、根因与处理

### 4.1 多视图公共骨架可能产生重复控件和状态冲突

- 现象与风险：若分别保留图形搜索和列表搜索，容易出现重复 id、查询不同步及视图状态互相覆盖。
- 处理：只合并一次公共骨架，共享搜索移出图形工作区；完整列表保留服务器生成的无脚本基线，成功初始化后再开放增强控件。
- 验证：图形与列表间切换保留查询，空结果及清空恢复、定位隐藏目标、无脚本和失败回退均经真实浏览器检查。

### 4.2 当前真实数据没有30天内临期节点

- 现象：浏览器首轮排序回归没有发现临期标签，不能据此宣称“真实临期样本已验收”。
- 根因：2026-11-26 当前数据最早保质期为0005的2027-01-01，超过既有30天提醒窗口；页面没有生成标签是正确行为。
- 处理：不修改节点日期或提醒阈值制造样本。保留当前数据的无重复标签检查，另将浏览器时钟固定为2026-12-15，使用真实0005日期验证首页和详情均只生成一个“临期 · 还剩 17 天”标签。
- 验证：固定时钟下首页计算、详情计算及标签唯一性均通过；该结果证明交互逻辑，不冒充2026-11-26已有真实临期节点。

### 4.3 既有证据警告不属于本轮消除对象

- 现象：最终校验仍报告22个证据多样性及派生证据警告。
- 根因与边界：这些警告来自既有节点证据结构，本轮没有进行逐项实质复核。
- 处理：原样保留，不为消除警告替换链接、删除证据、修改关系或调整节点判断。
